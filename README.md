# ark-coast.com

Company page for Ark Coast. It's a single static page that links to our Amazon storefront. All sales happen on Amazon.

Hosted on GitHub Pages from the `main` branch root. There's no build step, so edit `index.html`, push, and the site updates within a minute or two.

## Files

- `index.html`: the page (content and styles)
- `favicon.svg`: browser tab icon
- `CNAME`: custom domain for GitHub Pages (don't delete)
- `.nojekyll`: tells GitHub Pages to serve files as-is
